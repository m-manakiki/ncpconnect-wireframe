NCPConnect wireframe

A clickable mobile wireframe of both NCPConnect apps, built from the 19 feature walkthrough decks and the desk/NCP console mockups in docs/NCPConnect-mockups-main.

How to use

Tap anything inside the phone. Lists, cards, buttons, chips, toggles, stars, keypads and the SOS button all respond. Bottom tabs switch between the main destinations of each app. The ← key goes back.

The Screens tab lists every screen by app and feature. The Coverage tab lists every capability from the decks and ticks the ones a screen implements; tap a line to jump to that screen.

Reading the wireframe

Section numbers like §3.22 are the capability IDs used in the decks. They appear on screens so engineers can trace a control back to the spec.

Desktop-only consoles (org structure, master-data workbench, poll-day command centre) are shown as compact mobile views so no feature is missing; the decks mark them desktop-primary.

For the Flutter build

Each screen id (for example L.g.ticket) maps to one route. The component vocabulary (list, card, timeline, chips, segmented control, bottom sheet, keypad, hold-to-confirm) maps directly to Material widgets.
